# 单次作业评分细则（模板）

> 复制本文件到 `rubrics/<章节>.md`，按当次作业改写。公共档位见 [`../docs/grading.md`](../docs/grading.md)。
> 本模板以"电路基础 第六章"为例，不含任何学生信息。

## 作业信息

- 课程：目标课程
- 作业：第六章作业（电容与电感）
- 满分：10
- 提交要求：思维导图 + 6.11、6.19、6.32、6.46、6.51、6.62 的手写过程与最终答案
- 排序依据：批改页左侧列表顺序

## 分数档

| 情况 | 分数 |
|---|---:|
| 完整且主要解答正确 | 10 |
| 1 题实质错误或明显未完成 | 9.5 |
| 2 题实质错误或明显未完成 | 9 |
| 更多题错，或缺思维导图 | 8 |
| 大量缺答 / 只交导图 / 章节误传 | 7 |
| 仅导图 | 7.5 |

书写工整可 +0.5，上限 10。

## 每题核对点

| 题 | 必须核对 |
|---|---|
| 6.0 | 电容/电感 VCR、储能、串并联、直流稳态 |
| 6.11 | 分段积分、连续性、关键点 10/17.5/12.5/12.5/17.5 V |
| 6.19 | 逐步化简，最终 10 μF |
| 6.32 | 电荷 → 电压 → 储能；注意 v₁/v₂ 标号 |
| 6.46 | 直流稳态，i_L=2A、v_C=0、w_L=1J、w_C=0 |
| 6.51 | 中间值 10/35mH 不算答案，最终 70/9 mH |
| 6.62 | i₂(0)=−10mA；两个电流的常数项不能漏 |

## 高频错误（评语里优先点）

1. 6.62(b) 漏初值/稳态常数项；
2. 6.32 储能漏 `(1−e^(−2t))²`，或 mA 未换成 A 导致量级错；
3. 6.46 把 v_C 当成某个电阻上的压降；
4. 6.51 把中间值当最终答案；
5. 6.19 串并联混用。

## 评语要求

- 120–300 字，中文，点题号、错因、正确值；
- 不空泛、不人格评价、不判抄袭；
- 不使用反引号与换行，指数写成 `^`。
