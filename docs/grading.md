# 评分规则与评语写法

> 本文的档位来自一次真实课程的**用户偏好**（0–10 分制，保底 7 分），不是雨课堂或学校的通用标准。换课程、换老师时请重写本文，或为单次作业单独建 `rubric.md`。

## 1. 基本档位

| 可验证的作业情况 | 基础建议分 |
|---|---:|
| 完整且主要解答正确 | 10 |
| 1 道题有实质错误或明显未完成 | 9.5 |
| 2 道题有实质错误或明显未完成 | 9 |
| 更多题出错，或缺少思维导图 | 8 |
| 大量缺答、缺少大量最终答案、主要提交内容不属于本次作业 | 7 |
| 只提交了思维导图 | 7.5 |

补充：

- **按题计错**，不按笔误处数累计；同一道题的连带错误算 1 题。
- 字迹工整、排版清晰、结构规范，可加 0.5，上限 10 分；"勉强能看清"不算加分。
- 只给波形没写表达式、只给答案没给过程、单位/科学计数法不规范：属于小瑕疵，写进评语，不单独降档。
- 不因"参考答案可疑"判学生错；先核对题纸参数（见 [`answers-ch6.md`](answers-ch6.md)）。
- 不使用系统"迟交自动 0 分"规则，除非当次任务明确要求。

## 2. 判分要看什么

对每一道题，内部记录四件事：

1. **方法**：用的公式/定理对不对（分压分流、串并联、储能公式、磁链守恒…）；
2. **过程**：关键步骤有没有，是否只写答案；
3. **结果**：数值、符号、指数、单位；
4. **完成度**：是否漏题、是否只写了一半。

一个学生可能"结果对但过程跳步"或"过程对但算错一个数"。前者通常不扣，后者按"1 题实质错误"处理。

## 3. 评语规范

- 中文，120–300 字；**必须具体**：点出正确的关键结果、错在哪一题、错因、正确值。
- 不写模板空话，不做人格评价，不判断抄袭。
- 不声称看过没看过的内容；不确定就写"请补拍/请核对"。
- 避免反引号和换行（会破坏填表）；指数用 `^`，例如 `(1-e^-2t)`。
- 高分也要给改进点；低分要说清楚为什么。

模板（按事实改写，不要直接套）：

```
完整且正确：
思维导图与习题齐全，主要结果正确，过程清楚。请继续保持，注意最终结果的单位与标注。

一题未完成：
整体完成较好。6.62(b) 请把积分化简，并补齐 i1(t)、i2(t) 的最终表达式及单位。

参数存疑：
6.32 请核对题纸给出的电流参数，并用含 t 的表达式写出各电容储能。

章节误传：
当前上传内容为第七章习题，未见本次指定习题与思维导图，疑似误传，请核对并补交。
```

## 4. 匿名案例

以下案例由真实批改记录改写，姓名与标识均已替换。它们说明"分数如何解释"，不是让学生对号入座。

### 案例 A：整体完整，一处公式有问题 —— 10 分

- 提交：2 张图片，思维导图 + 全部计算题。
- 判断：六道题里五道关键结果正确；6.32 的储能写法没有体现"电压平方"，属于方法表述问题，不影响其余结果。
- 处理：用户此前明确"这类完成度可以给 10"，结合书写清楚，最终 10 分；评语里点名 6.32 的公式。
- 评语：`思维导图与习题齐全，主要结果正确、书写清楚。6.32 储能应使用 w=1/2·C·v²，请注意电压平方及单位。整体完成认真，结合书写规范给予鼓励。`

> 满分不等于零错误。评语里的具体问题才是可复核的部分。

### 案例 B：PDF 三页，但大部分题没做 —— 7 分

- 提交：3 页 PDF，有本章思维导图和第一道题的波形；最后一页是另一门课的力学内容，其余五道指定题没有解答。
- 判断：不是"加载失败"，也不是"页边距空白"——三页都读完了才确认缺答；末页内容属于章节误传。
- 处理：按"大量缺答"给保底 7 分，评语说明疑似误传并请补交。
- 评语：`已提交本章思维导图和 6.11 波形图。当前 PDF 未见 6.19、6.32、6.46、6.51、6.62 的解答，末页为力学内容，疑似误传，请核对并补齐指定习题。本次按宽松标准给予 7 分。`

### 案例 C：最后一题停在积分中间 —— 9.5 + 0.5

- 提交：3 张图片，导图完整，前五题主要计算正确；6.62(b) 写到积分式就停了，没有给出 i1(t)、i2(t) 的最终表达式。
- 判断：属于"1 道题明显未完成"，基础 9.5；书写规范清楚，加 0.5，最终 10。
- 评语：`思维导图与习题均有提交，主要计算正确、书写清楚。6.62(b) 请将积分化简并补齐 i1(t)、i2(t) 最终表达式，注意结果单位。结合整体完成情况和规范书写给予鼓励。`

### 案例 D：参数与参考答案不同 —— 不判错，保留提示

- 提交：3 页 PDF，题目与导图完整；6.32 使用的电流参数与本地参考答案不同，储能也没有写成含 t 的通式。
- 判断：学生引用的是题纸自己印的参数，按该参数推导自洽；本地参考答案本身还有标号疑点。因此不判错，只在评语提醒核对参数。
- 处理：其余结果一致，书写工整，最终 10 分。
- 评语：`作业与思维导图完整，书写工整、结构清晰。6.32 请核对题目电流参数，并用含 t 的表达式给出各电容储能。其余主要结果正确，结合规范书写给予鼓励。`

## 5. 分数怎么解释

- 10 分是"在这个宽松标准下、结合书写加分后的最终成绩"，不是"零错误"标签。
- 7 分通常意味着主要缺答、章节误传或只交了导图，而不是"错了一两道题"。
- 需要复核时，保留每题依据（方法/过程/结果/完成度），不要只凭分数反推作业质量。
- 个别学生的特批分数（例如用户点名）只对那次作业有效，不要写成通用规则。

## 6. 换课程时怎么改

1. 复制本文件为当次作业的 `rubric.md`；
2. 改写档位（如果用户给了新标准）、题号、每题核对点；
3. 把"内部记录"字段保留，评语模板按学科调整；
4. 在批次记录里注明"本次使用的规则文件"，方便以后追溯。
