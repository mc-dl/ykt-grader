# 第六章核对表与答案勘误（示例）

> 本文是"如何组织答案核对材料"的示例，不是通用答案库。
> 只保留可公开核对的**结论与勘误**；教材答案原文、扫描件、教师姓名等不入库。
> 换章节时，按同样结构新建 `answers-<章节>.md`。

## 1. 本次作业范围

- 思维导图（电容、电感：定义、伏安关系、储能、串并联、直流稳态）
- 6.11、6.19、6.32、6.46、6.51、6.62 六道计算题

参数版本：中文版教材（部分学生题纸印的是另一版参数，见第 4 节）。

## 3. 推导要点

- **6.11**：`v(t)=v(0)+(1/C)∫i dt`。每段积分上限取上一段末值，注意第三段电流为 0 时电压保持 12.5V。
- **6.19**：电容串联 `C₁C₂/(C₁+C₂)`，并联相加；按节点从右往左逐步化简。
- **6.32**：先求电荷 `q(t)=∫i dt=2.25×10⁻³(1−e^(−2t)) C`，再由 `v=q/C` 得 12μF 上 187.5 倍、60μF 上 37.5 倍；储能 `w=½Cv²`。
- **6.46**：直流稳态电容开路、电感短路。`i_L` 用分流定理，`v_C` 是两个支路压降之差（本题恰为 0）。
- **6.51**：先并联 20/30/60 得 10mH，再与 25mH 串联得 35mH，最后 35‖10。
- **6.62**：`v=L_eq·di/dt` 积分求总电流；并联分流 `i₁=(60/80)i`、`i₂=(1/4)i`；由 `i₁(0)` 定积分常数。

## 4. 已发现的答案疑点

### 6.32：v₁ / v₂ 标号不能照抄

本地答案的"最终答案"把两个电压写成 37.5 和 187.5，但同文件的能量行对应的是另一种标号，文件自身已提示疑似错位。

处理原则：**按元件本身算**，不要按 OCR 出来的下标记答案。同一串联支路电流相同，12μF 上电压是 60μF 并联组的 5 倍。若学生给出的 v₁/v₂ 与参考相反，先看题图实际标注，再判断对错。

### 6.11：文字抽取笔误

原文曾出现 `3.76t`、`22.5+2.5t`，按电流积分与电压连续性应为 `3.75t`、`22.5−2.5t`。学生按正确推导写出的结果不应因"与错字答案不一致"被扣分。

### 6.62：初始条件不能无条件推广

本题由 `i₁(0)` 经磁链守恒推出 `i₂(0)`。一般并联电感不能只凭电感值就认定初始电流按比例分配；不要把本题的特殊处理套到其他初始状态。

### 版本差异

同一题号在国际版/不同印次中参数可能不同（例如电流幅值、初值）。以学生题纸为准；如果学生按题纸参数推导且自洽，不判错，只在评语提醒核对参数。若出现量级错误（电压到 10⁵–10⁶ V、储能成 kJ），无论哪个版本都算错——多半是 mA 没换成 A。

## 5. 自备答案怎么放

教材答案原文通常有版权，**不要提交到公开仓库**。建议：

```
answers.local/            # 已在 .gitignore 中
├── 6.11.md
├── 6.19.md
...
```

Agent 读题时按 `answers.local/` → `docs/answers-*.md` 的顺序查找。换课程时，让 Agent 先读你提供的答案文件，再开始判分。
